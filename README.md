# LAST WAY STALKER RP — база знаний

Статический сайт-энциклопедия для публикации на GitHub Pages.

## Что внутри
- Главная страница с каталогом материалов
- Поиск по статьям и фильтры по категориям
- Страницы-заготовки: лор, правила, фракции, разработки, мир Зоны, документы, экипировка, памятка новичка
- Адаптивная вёрстка для компьютера и телефона

## Публикация на GitHub Pages
1. Создайте публичный репозиторий на GitHub.
2. Загрузите **все файлы и папки** из этого архива в корень репозитория.
3. Откройте `Settings` → `Pages`.
4. В `Build and deployment` выберите `Deploy from a branch`.
5. Выберите ветку `main` и папку `/ (root)`, нажмите `Save`.
6. Через некоторое время сайт появится по адресу `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

## Как редактировать
На первом этапе статьи-заготовки хранятся в `app.js` в объекте `articles`. Для изменения текста найдите нужную секцию и замените содержимое. Главная страница и карточки находятся в `index.html`.

## Важно
Сайт публично читаемый. Изменять его содержимое могут только те, кому вы дадите права на запись в GitHub-репозиторий. Не публикуйте личные данные, закрытые служебные сведения или материалы, которые не должны быть доступны всем.
